【C 盘守卫 · 桌面版 v6.17 使用说明】
（本文档随代码同步更新，发版前由 _check_docs.py 自动校验一致性）

一、这是什么
  一款带图形界面的 C 盘保护软件。v6.7 起界面换新：**左侧竖排导航**，
  点一下切换页面，选中的会高亮成绿色。左侧栏底部会一直显示「正在守护 C 盘」。

  启动后显示主窗口，左侧栏从上到下一共 9 个页面（顺序与软件一致）：
    · 概况     —— C 盘使用状态（大圆环仪表盘）、全部磁盘总览、环境自检、体检报告入口
    · 今日新增 —— 今天 C 盘多了哪些内容、来自哪个软件、占多少空间，
                  勾选后可「一键移动」到其他盘
    · 存量盘点 —— 装守卫之前这些空间是谁占的（按月记账、九类白话分类）
    · 日志清理 —— 偷偷长大的日志 / 崩溃记录 / 临时文件，该删就删（详见第十一章）
    · 守卫记录 —— 每一次询问与决定的留痕（CSV 日志的可视化）
    · 隔离区   —— 被删除保护的文件留在这里，可一键还原
    · 软件迁移 —— 整个软件目录搬到别的盘，快捷方式 / 注册表 / 服务引用
                  一起处理，先给风险等级再动手（详见第十三章）
    · 联动盘   —— 软件的数据实际放别的盘，C 盘只留一个「门牌号」；
                  首次打开软件、或它在 C 盘超过 2GB 时主动提醒（详见第十四章）
    · 设置     —— 守护开关（滑块）、阈值、开机自启、软件存储限制、
                  监控盘与拦截白名单

二、换台电脑怎么用（v6.11 重点）
  1. 只下载 GitHub Releases 页面【最新版本】的 zip（旧版本的附件可能已过时）。
  2. 必须先解压再运行！不要在压缩包里直接双击 exe。
  3. 程序启动后会自动适配这台电脑：读取本机用户名、监听整个系统盘、
     生成本机自己的配置和数据，绝不会带着上一台电脑的旧数据。
  4. 打开「概况」页 →「环境自检」卡片：版本、数据目录、监控范围、
     监听线程一目了然。全绿 = 本机适配正常、拦截已生效；
     红色「拦截未生效」= 按卡片里的提示处理（见下一条）。
  5. 排障：点「复制诊断信息」，把剪贴板内容发给开发者即可远程定位。

三、第一次运行被 Windows / 杀毒软件拦住怎么办
  · Windows 蓝色弹窗「Windows 已保护你的电脑」→ 点「更多信息」→「仍要运行」。
    （程序未做付费签名，首次运行会有此提示，属正常现象）
  · 360 / 电脑管家等若弹出拦截，请选择「允许」并把 C盘守卫.exe 加入信任区；
    若它们把询问弹窗自动关掉，守卫会按最安全的默认处理并在记录里说明。
  · 程序完全本地运行、不联网，源代码全部公开可审查。

四、关闭 ≠ 退出（重要）
  · 点主窗口右上角 × ：窗口缩到系统托盘（屏幕右下角），守卫仍在后台
    保护 C 盘，托盘图标会弹一次气泡提醒。
  · 真正退出：右键托盘图标 →「退出守卫（停止保护）」→ 确认。
  · 开机自启：默认已注册（启动后直接缩在托盘）；可在「设置」页关闭。

五、写入询问（新版流程）
  当有新文件要写进 C 盘时，会弹出询问窗口：
    【是】仍然保存到 C 盘
    【否】弹出二级选择：
        · 选其他本地盘（D/E/F…，按剩余空间排序）→ 移动到该盘
        · 浏览文件夹…（自选任意位置）
        · 取消：不安装、不下载、不存储 —— 立即删除刚写入的内容
        · 返回：还是留在 C 盘
  技术说明（如实告知）：Windows 普通应用无法在文件"写入前"拦截（那需要
  内核驱动）。本软件采用"落盘即询问"：文件刚出现的瞬间弹窗，你选"否"
  后秒级搬走或删除，实际效果等同"没存进 C 盘"。
  v6.14 补充：内核级"写入前拦截"需要驱动签名、WHQL 认证和 64 位兼容，
  稳定性代价太高，本软件不做内核驱动；同时新增「落盘后秒级迁移」——
  在「设置 → 监控盘选择」里开启后，命中你设的软件限制规则、且你为该
  软件指定过目标盘时，文件落盘稳定 1 秒后自动搬走，不再弹窗。

六、用户目录新文件夹拦截（v6.1 新增）
  · C:\Users\你的用户名 下出现任何新文件夹（不看点开头、不看大小），
    都会弹窗询问，例如 .android、Doubao 这类软件自建的目录。
    弹窗三个选择：
    【保留在 C 盘】以后不再问这个文件夹
    【搬到其他盘并创建链接（推荐）】文件夹实体移到其他盘，原位置留一个
      透明链接（junction），相关软件照常使用，C 盘空间立即释放
    【稍后再问】1 小时后再提醒
  · OneDrive、桌面/文档/下载等系统固定目录在白名单内，不会打扰。
  · 搬移失败（文件夹正被占用）会自动回滚，原地保留，绝不丢数据。

七、今日新增监测（现在可以检测电脑上任意一块盘）

7.1 检测位置：想看哪块盘就选哪块盘
  · 页面顶部「检测位置」下拉会**自动列出你电脑上的每一块盘**——本地硬盘、
    U 盘、移动硬盘都会自动出现（空的光驱、没插卡的读卡器会被自动过滤）。
    例如你的电脑有 C/D/E/F 四块盘，下拉里就有四个选项；
    只有 C 和 D，就只显示 C 和 D。插上 U 盘也会自动出现。
  · 每一项都带实用信息：盘符、卷标名字、总容量、还剩多少、占用百分比。
    例：C 盘 · 系统　剩 20.7 GB / 59.4 GB（占用 65%）
  · 下方的彩色长条是这块盘的**健康条**：
    🟢 良好（占用 <75%）｜🟡 偏紧（75%~88%）｜🔴 告急（≥88%，会提示清理）
  · 换一块盘后，列表立刻变成那块盘今天的扫描结果（每块盘的纪录分开保存，
    互不干扰）；想看最新的，点「🔄 扫描今日新增」重新扫一遍即可。
  · 扫非系统盘时是整盘扫描（限 4 层深度、自动跳过回收站等系统目录），
    高速扫描已开启，文件再多通常十几秒～一分钟，界面不会卡，可以先做别的事。

7.2 排序：占用大 / 时间新 / 来源应用，随你切换
  · 页面右上「排序」下拉提供 7 种排法：
      占用大的排前面 ｜ 占用小的排前面
      最新出现的排前面 ｜ 最早出现的排前面
      按来源应用排序 ｜ 按所在位置排序
      要注意的排前面（搬移风险）—— 不能搬的自动排到最顶部
  · **也可以直接点列表的表头排序**：点一下升序、再点一下降序。
    「大小」「新增时间」「来源应用」「文件数」「移到别的盘会怎样」都能点。

7.2.1 【新增】「移到别的盘会怎样？」—— 专门给不懂电脑的朋友看的一列
  · 这一列在「文件数」后面，用大白话直接告诉你：
    把这块内容搬到别的盘，会不会让软件用不了、会不会把程序搞坏。
  · 共分 6 种说法，一眼就懂：
      个人文件 · 可放心搬    （绿）照片、电影、文档、安装包之类，随便搬
      缓存/日志 · 可放心搬    （蓝）软件自己产生的临时数据，搬掉它反而更干净
      软件数据 · 先退出软件    （蓝）某个软件自己的资料，先把它完全退出再搬
      程序安装位置 · 谨慎     （橙）软件装在哪；搬前一定先退出，个别要重装
      云盘同步中 · 不建议搬    （红）正在同步的位置，要改请在网盘客户端改
      系统文件 · 不要搬      （红）Windows 自己的地盘，碰它可能开不了机
      已不在系统盘 · 无需搬    （灰）本来就在别的盘，不用操心
  · 鼠标停在这一列上，会弹出完整的文字说明（比如"建议先退出某某软件，
    包括右下角任务栏的小图标"）。
  · 列表正下方有一行图例，六种颜色都标出来了。
  · 记住两条就够：**绿色蓝色＝可以搬；红色＝不要碰。**

7.2.2 为什么大多数情况下搬了也没事？
  · 本软件搬家用的是「先复制过去 → 成功后在原位置留一个目录联接(junction)」，
    说人话就是在原地址立一块「请去隔壁找我」的门牌。
  · 所以对软件来说，路径压根没变，它自己根本察觉不到，也不会出错。
  · 真正有风险的只有三类：Windows 系统自己的文件、正在和云端同步的位置、
    以及正在运行被占用的程序文件 —— 这三样本软件都会标红提醒你。

7.2.3 两道自动保护
  · 点「全选」时，标红的两类（系统文件、云盘同步）会被**自动跳过**，
    不会被一起勾上，底部会提示"自动跳过 N 组不建议搬动的内容"。
  · 万一你手动勾了标红的内容再点「一键移动」，会先弹出明确警告、
    列出是哪些项，默认停在"否"上，确认后才继续。

7.3 占盘%：一眼看出"是谁占了这块盘"
  · 新增的「占盘」列显示：这一组内容占了该盘**已用空间**的百分之多少。
  · 颜色分级：≥10% 标红（重点关注）、≥2% 标橙、其余常规色。
  · 鼠标悬停会显示更精确的数字（如：占 C 盘已用空间 38.8 GB 的 2.27%）。

7.4 列表原有内容
  · 列表按「来源应用 + 所在目录」聚合：显示来源（微信/QQ/浏览器/网盘…，
    按路径特征归因）、新增时间、占用大小、文件数。
  · 新增时间：格式为「年.月.日  时:分」，例如 2026.11.01  00:30。
    优先取文件创建时间（非今天创建的文件则取最后修改时间）。
    单个文件/同一时刻显示一个完整时间；
    同一目录多个文件显示「最早 ~ 最晚」区间（同一天则后半段省略日期，
    如 2026.11.01  01:28 ~ 03:39；跨天才显示两段完整日期）；
    鼠标悬停可看到该组最早与最晚的完整时间；
    点开父行（▶）可看到每个文件各自的完整新增时间。
  · 定位到 C 盘真实位置：双击任意一行（父行=所在文件夹，子行=具体文件），
    或选中后点底部「📂 打开所在位置」，即在资源管理器里打开对应文件夹；
    文件会自动选中。
  · 勾选行（第一列）→ 底部选目标盘 →「📦 一键移动所选」。
    目标盘列表会**自动排掉你正在检测的这块盘**（不能搬到自己），
    并按剩余空间从多到少排列，方便你挑最空的盘。
    移动采用"先复制、成功后删源"，失败项原地保留，绝不丢数据；
    AppData 里的软件目录会连同原位目录联接一起搬（软件无感）。

7.5 【v6.14 新增】来源详情核验与手动修正
  · 右键任意一行 →「🔍 查看来源详情（签名 / 进程）」：读取该目录里 .exe
    的数字签名（发布者、是否验证通过），并列出当前正在运行的相关进程，
    不再只靠关键词猜。
  · 觉得认错了？右键 →「✏️ 修正来源应用…」，写上正确的软件名，
    同一目录下的文件以后都按你写的名字显示，保存后立即重新扫描生效。
  · 设置 →「深度来源识别（数字签名 / 进程关联）」开启后，每次扫描会对
    前 20 个来源目录自动核验签名与进程（结果带缓存，稍慢但更准）。

八、概况页「全部磁盘总览」—— 守护电脑上的每一块盘
  · 打开软件第一页就能看到电脑上**所有盘的实时状态**，每块盘一行：
    健康图标 + 盘名 → 彩色占用条 → 已用/总容量/剩余/百分比。
  · 每行右侧两个按钮：
      【看X盘今天多了什么】一键跳到今日新增页并把检测位置切到该盘
      【打开该盘】直接在资源管理器里打开这块盘
  · 卡片底部会自动给出一句建议：
      "💡 空间最宽裕的是 F 盘（剩余 455.8 GB），把软件、下载、
        微信文件放到它上面，C 盘就不容易告急。"
  · 空间告急（≥88%）的盘会明确标红提示，提醒你及时清理或搬移。
  · 所有数据每 60 秒自动刷新一次；插拔 U 盘后下拉列表也会自动更新。

九、关于"拦截写入"的范围（v6.14 更新）
  · 默认仍只拦截**系统盘**的写入——往 D/E/F 盘存文件本来就是正常需求，
    若也逐个弹窗，一天会弹上百次，反而没法用。
  · v6.14 起你可以在「设置 → 监控盘选择」里勾选要拦截的盘（详见第十二章），
    也可以用「拦截白名单」让某些目录 / 进程的写入直接放行。
  · 所有盘的**占用查看、今日新增检测、一键搬家**依旧是全盘支持的。
  · 也就是说：默认系统盘享受"拦截 + 监控 + 搬家"全套保护，
    其他盘提供"看得清 + 搬得走"的能力，想拦哪块盘由你自己勾。

十、软件存储限制 —— 我自己说了算（新功能）
  不想让某个软件往 C 盘塞东西？自己加一条规则就行。
  软件里**没有预置任何品牌名单**，限制谁、不限制谁，全部由你手动决定。

  10.1 两种添加方式
   ① 从电脑里选（推荐，不用猜名字）：
      设置 →「软件存储限制」→「管理被限制的软件」→「添加软件」，
      窗口会自动列出你电脑里**已安装的软件**和**下载的安装包**，
      在列表里点一下选中，名称和识别关键词会自动填好，确认后点「添加」。
      列表太多就在上面的搜索框输一下（比如 kugou 或 酷狗）。
   ② 列表速加：在「今日新增」列表里，对着某一行点右键 →
      「禁止这个软件存到 C 盘」，会自动带上识别用的关键词。

  10.2 关键词怎么填（最关键的一步）
    · 关键词决定"能不能认出是这个软件"，用逗号分隔，中文英文都行。
    · 举例：软件文件夹叫 KuGou，你只填中文「酷狗音乐」就认不出来，
      所以要写成：酷狗音乐, KuGou, kugou
    · 用第 ② 种方式添加时，软件会自动从路径里把英文目录名补上，
      一般不用自己操心。

  10.3 命中之后会怎样
    被你限制的软件一往 C 盘写东西，守卫立刻弹窗问你，四个选项：
      ① 搬到别的盘（推荐）→ 你选一个盘 → 自动搬走，原位置留链接，
         软件照常能用，C 盘马上腾出空间
      ② 这次就放 C 盘（仅此一次，下次再问）
      ③ 不下载 / 不安装（把刚写入的内容删掉）
      ④ 解除限制（以后这个软件可以正常存 C 盘）
    · 同一条规则 90 秒内只问一次，不会一直弹窗烦你。
    · 开启「落盘后秒级迁移」并为该软件指定过目标盘时，落盘后直接搬走，
      不再弹窗（见第五章）。

  10.4 不想看到任何软件名称
    设置 →「来源显示方式」，把"用内置对照表把路径翻译成软件名"取消勾选，
    之后「来源应用」这一列只显示文件夹名。
    （这张对照表只是本地文字关键词，不含任何图标，也不联网）

十一、日志自动清理 —— 让 C 盘不再"什么都没干也在变少"（新功能）
  11.1 为什么需要它
    · 软件日志、崩溃记录、临时文件会一直偷偷长大。比如某个软件的日志
      一天就能写几百 MB —— 你什么都没干，C 盘却在一点点变少。
    · 这类东西**不该搬走，直接删掉最合理**：删了软件照样能跑，
      最多重新生成一份新日志。

  11.2 怎么用
    ① 打开「🧹 日志清理」标签页 → 点「🔍 立即扫描」
    ② 看列表：在哪些位置、多少个文件、多大、为什么可以清
    ③ 勾选要清的位置 → 点「🧹 清理勾选的内容」
    · 双击任意一行，直接打开那个文件夹看看
    · 点表头可以按「大小 / 最后写入时间 / 类型」排序

  11.3 它只清三类东西
    · 日志文件（.log 等，以及 log / logs 目录里的文本记录）
    · 崩溃记录（.dmp，软件崩溃时生成的）
    · 临时文件夹里的旧文件（Temp）
    文档、照片、视频、安装包、软件本体 —— 一律不碰。

  11.4 四条安全底线
    ① 系统目录永不触碰：Windows、Program Files、ProgramData 全部跳过
    ② 只删「N 天没动过」的（默认 3 天），或「大到离谱」的（默认 50 MB 以上）
    ③ 正在被软件写入的文件：不会自动删，只在列表里标成橙色提示
       「建议先退出对应软件再清」—— 避免删到一半软件还在写
    ④ 自动清理默认关闭，需要你自己打开

  11.5 开启自动清理
    在「🧹 日志清理」页下半部分的设置区，改完点「💾 保存自动清理设置」：
      · 开启自动清理                总开关（默认关）
      · 超过多少天没动过就可以清      默认 3 天
      · 单个文件大到多少 MB 就可以清   默认 50 MB
      · 每隔多少天自动清理一次        默认 7 天
      · 可清量少于多少 MB 就不打扰     默认 20 MB（不够多就不烦你）
      · 清理前先问我一次             推荐开启（默认开）
    开启后程序每 30 分钟检查一次是否到期：到期就自动扫一遍，
    够量就按上面的条件清理，不够量就悄悄跳过，不打扰你。
    清理完成后托盘会提示「腾出了多少空间」。

  11.6 【v6.14 新增】模拟运行 —— 先看清单，再决定删不删
    · 点「🧪 模拟运行（先列清单）」：把准备删除的每一个文件、预计释放的
      总空间一次性列出来 —— 此刻一个字节都不会删；
    · 你在预览窗口点「✅ 确认执行清理」之后才会真正删除。
    · 自动清理也有「模拟运行」开关：开启后到点只报告「找到多少文件、
      预计释放多少」，不删除任何东西；关掉它才会真正清理。

  11.7 【v6.14 新增】更细的清理规则
    · 只清这些类型：填扩展名（如 .log, .dmp），留空 = 三类都清
    · 目录白名单：这些目录及其子目录一律不碰，优先级最高
    · 单次累计上限 MB：累计到顶就停，避免连续处理海量小文件
      （0 = 不限；单个文件自己就超预算时会跳过它、继续清小的）

十二、可选监控盘 + 拦截白名单（v6.14 新增）
  12.1 监控盘选择
    · 「设置 → 监控盘选择」：勾选要拦截写入的盘；不勾任何盘 =
      只保护系统盘（与以前完全一样）。
    · 保存后监听线程 15 秒内自动同步，不用重启程序。
    · 勾选「U 盘插入时自动纳入监控」：U 盘插上自动加监听、拔出自动摘除，
      拔掉再插上也不会漏。
    · 换电脑放心：配置里勾选的盘符在新电脑上不存在时会被自动剔除，
      一个都不剩就回落到系统盘，绝不会因为带着旧配置而让拦截失效。
  12.2 拦截白名单
    · 「设置 → 拦截白名单」：每行一条，填目录（如 D:\Games）或路径片段
      （如 SteamLibrary）；以 .exe 结尾的按进程名处理（如 OneDrive.exe）。
    · 命中的写入直接放行、不再弹窗 —— 只做减法，不改文件、不删数据。
    · Windows、Program Files 等系统目录的自动排除不受影响。

十三、软件迁移向导（v6.14 新增）
  有些软件搬走目录后会打不开，因为原来的路径被写死在快捷方式、注册表
  或 Windows 服务里。这个向导把这些引用一起处理，一共四步：

  13.1 刷新软件列表
      自动列出已安装软件与绿色软件的安装目录，按体积排序、带来源标签。

  13.2 生成迁移计划（模拟运行）
      选中软件、选好目标盘后点一下，程序**只读**检查快捷方式、注册表、
      Windows 服务三类引用，并给出迁移风险等级：
      · 高：有 Windows 服务 / 驱动文件 / 系统保护目录 —— 建议卸载后
        重装到目标盘；确要继续需二次确认，服务程序绝不会擅自修改。
      · 中：有开机自启动项或注册表安装信息（可自动替换，替换前先备份）。
      · 低：只有快捷方式，或没有任何外部引用。

  13.3 执行迁移
      按「复制 → 逐项校验 → 更新快捷方式 → 替换注册表 → 原位置留透明
      链接」的顺序进行；目标盘空间不足、复制校验失败、建链接失败……
      任何一步失败都会立即还原，绝不留半吊子状态。

  13.4 不满意随时撤销
      点「↩️ 撤销一次迁移」，数据搬回原位置，快捷方式与注册表引用
      一并还原。

十四、联动盘 —— 软件的数据放别的盘，C 盘只留「门牌号」（v6.15 新增）
  一句话：把软件在 C 盘的数据目录搬到别的盘，C 盘原地址留一个透明链接
  （junction）。软件照旧按老地址读写，它自己完全感觉不到搬家；C 盘空间
  立刻腾出来，以后新产生的数据也自动落到别的盘。

  14.1 什么时候会主动提醒你
      · 你**第一次打开**某个软件（它刚开始往 C 盘存东西）
      · 某个软件在 C 盘的数据**超过阈值**（默认 2GB，页面里可改 0.5~100GB）
      第一次装好守卫时不会一次问一堆：只把当时开着的软件静默登记，
      其中已经超过阈值的才会提醒一次（比如微信已经 5GB）。
      弹窗里会说清三件事：它占了哪些目录、建联动盘有什么好处、怎么反悔。
      三个选择：
        【好，建联动盘】→ 下一步选放到哪个盘，立刻开始搬
        【先不用】    → 7 天内不再问这个软件
        【以后别再问】→ 这个软件永久不再提示

  14.2 搬的时候做了什么（为什么不会把软件弄坏）
      ① 先复制到目标盘（robocopy）
      ② 逐目录核对文件数与字节数，对不上就放弃
      ③ 源目录改名保留 → 在原位置建 junction
      ④ 链接确认可读之后，才删掉旧副本
      任何一步失败：源目录改名还原、目标副本清理，软件保持原样。
      数据正被软件独占写入时会失败并明确提示 —— 关掉软件再试即可。

  14.3 「联动盘」页怎么用
      · 列表：每个软件在 C 盘占多少、状态（未建 / 已建 / 不再提示）、数据在哪
      · 🔍 立即体检：把已安装但此刻没运行的软件也一起算一遍
      · 🔗 创建联动盘 / ↩️ 还原到 C 盘 / 不再提示（对选中的那一行生效）
      · 顶部可改：提醒开关、阈值、默认放到哪个盘
      · 列表上方显示：共记录多少软件、已建多少个、累计腾出多少空间

  14.4 它和「软件迁移」有什么区别
      联动盘只搬**数据**，不碰程序本体，所以完全不需要改快捷方式 / 注册表 /
      服务；软件迁移搬的是整个安装目录，必须处理那些引用（详见第十三章）。
      两者可以配合：程序用软件迁移，数据用联动盘。

  14.5 常见问题
      · 还原后 C 盘又满了？说明软件还在长数据，重新建一次联动盘即可。
      · 想换目标盘？先「还原到 C 盘」，再重新创建并选新盘。
      · 会影响软件更新吗？数据目录与程序目录分开，更新程序不受影响。
      · 目标盘拔了（U 盘/移动硬盘）？软件会读写失败 —— 联动盘请选固定硬盘。

十五、保留的原有能力
  · 聚合监控：网盘/聊天工具等目录涨大了才按"来源"问一次，不刷屏
  · 删除保护：检测到删除立即把数据抢进隔离区，清空回收站也能还原
  · 安装哨兵：软件装进 C 盘时提醒，可原位联接搬家
  · 空间告警：剩余空间不足时主动提醒
  · 体检/周报：概况页一键生成 HTML 报告

十六、安全保证
  · 只处理"新写入"的文件，绝不碰已有文件
  · 所有决定都记录在 guard_log\守卫记录_日期.csv
  · 「取消（不存储）」会删除刚写入的文件，删除前有二次确认
  · 软件迁移的每一步都是"先复制校验、成功后才动源目录"，失败自动还原

十七、常见问题
  · 弹窗没出现？请到 360/电脑管家「弹窗拦截」把 C盘守卫.exe 加入信任。
  · 想改默认接收目录？编辑同目录 config.json 的「转移目标」。
  · 双击没反应（提示已在运行）？看看托盘里是否已有守卫图标。
  · 搬走软件后它打不开了？到「软件迁移」页点「撤销一次迁移」，
    或按提示把服务重新安装一遍（程序不会擅自改服务）。
